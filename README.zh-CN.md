# TraceRoot

[English](./README.md)

**面向 agent skills 和本地 agent 运行时的开源信任基础设施。**

TraceRoot 是一个开源生态，目标是让 agent 生态更容易被检查、信任和加固。

## 项目

- [TraceRoot Audit](https://github.com/jwwzpf/traceroot-audit) —— 面向 agent skills 和本地 agent 运行时的开源信任与安全扫描器

## 关注方向

TraceRoot 聚焦于 agent 生态中真实且实用的信任基础设施，包括：

- skill 信任与供应链可见性
- 不安全的运行时与部署暴露
- 权限、provenance 与可审计性
- 面向开发者的检查与风险发现工具

## 当前状态

项目仍处于早期阶段。  
当前第一个核心项目是 [TraceRoot Audit](https://github.com/jwwzpf/traceroot-audit)。
