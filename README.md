# TraceRoot

[简体中文](./README.zh-CN.md)

**Open trust infrastructure for agent skills and local agent runtimes.**

TraceRoot is an open-source ecosystem for making agent ecosystems easier to inspect, trust, and secure.

## Projects

- [TraceRoot Audit](https://github.com/jwwzpf/traceroot-audit) — Open-source trust and security scanner for agent skills and local agent runtimes

## Focus

TraceRoot focuses on practical trust infrastructure for agent ecosystems, including:

- skill trust and supply-chain visibility
- unsafe runtime and deployment exposure
- permissions, provenance, and auditability
- developer-friendly tools for inspection and risk detection

## Status

Early-stage open-source ecosystem.  
The first active project is [TraceRoot Audit](https://github.com/jwwzpf/traceroot-audit).
